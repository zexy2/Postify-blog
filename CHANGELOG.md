## [0.1.0] - 2026-08-31

### Added

- First public product baseline for Postify as a Verified Knowledge network.
- Reproducible knowledge verification with explicit Unverified, Author tested, and Postify verified trust states.
- Supabase/PostgreSQL persistence with Row Level Security verification.
- Community Worked / Didn’t work evidence with privacy-safe public aggregates.
- React 19 application, TipTap editor, PWA support, multilingual product surfaces, and machine-readable knowledge artifacts.
- CI/CD gates covering unit tests, lint, production build, Chromium product tests, visual regression, database migration/RLS verification, deployment, and exact-SHA production smoke tests.
- Professional repository documentation, contribution guidance, security policy, issue forms, and pull request template.

### Security

- Secret scanning and push protection enabled.
- Private vulnerability reporting enabled.
- Dependabot alerts and security updates enabled.
- CodeQL default code scanning enabled for JavaScript/TypeScript and GitHub Actions.
- Main branch protected by required CI checks, pull-request flow, linear history, and force-push/deletion prevention.
